# zero-sql Official Website

Official website for **zero-sql**, a fast, privacy-focused desktop database client for SQLite, PostgreSQL, MySQL, DuckDB, and SQL Server.

## Features

- **Next.js & React App Router**: Deployed to Vercel.
- **SmartScreen Guidance**: Provides friendly installation steps for users encountering Windows SmartScreen prompts on newly published binaries.
- **Direct Installer Delivery**: Internal download endpoint serving the latest Windows desktop installer.

## Running Locally

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the website.
